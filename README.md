# 江江的个人主页

线上地址：<https://starvoid.top/>

单文件静态站点，无构建步骤、无依赖。页面最简：入场波浪结束后只保留名字「江江」，下面四行文案和一个 GitHub 入口，页脚一行备案信息。中文 / 英文可切换，明暗跟随系统，支持「减少动态效果」。

## 文件

```text
.
├── index.html      # 全部结构、样式、文案与动画
├── beian.png       # 页脚公安备案图标
├── robots.txt
├── sitemap.xml
├── .nojekyll       # GitHub Pages 不跑 Jekyll
└── README.md
```

## 本地预览

```bash
python3 -m http.server 8000
```

打开 <http://localhost:8000>。

## 代码结构

`index.html` 按顺序分四块：

1. `<head>`：meta、favicon，以及决定是否播放入场的 3 行内联脚本（`prefers-reduced-motion` 时不加 `intro` 类）。
2. `<style>`：七个分区——① 设计变量 ② 页面基础 ③ 顶栏控制 ④ 首屏与文案 ⑤ 入场状态 ⑥ 页脚 ⑦ 减少动态。
3. `<body>`：顶栏（重播 / 语言）、首屏与文案、页脚备案。
4. `<script>`：一个 IIFE，内部顺序为——元素引用、文案与元信息、运行状态、小工具、文案更新、入场动画、语言切换与重播、启动。

入场靠两个类驱动：

- `html.intro`：入场中。文案隐藏，欢迎语显示，名字缩到 `8.7vw`。
- `html.intro.grow`：第二阶段。欢迎语收起，名字放大回最终字号，文案浮现，渐变扫过文字。

动画结束后 `endIntro()` 会取消动画、移除两个类、清掉所有内联样式，页面回到纯静态状态。

## 入场时间线

| 阶段 | 时长 | 构成 |
| --- | --- | --- |
| 逐字波浪 | ≈1.39s | 每字 680ms 缩放，按字数错开；同段 900ms 渐变 |
| 收起 + 放大 + 文案 | ≈1.69s | 名字过渡 950ms，欢迎语 520ms、句号 360ms+120ms，文案 760ms/120ms 阶梯，渐变 1050ms/155ms+120ms 阶梯 |
| 合计 | ≈3.08s | 之后清空内联样式 |

相关常量都在 `playIntro()`、`playTextSweep()`、`revealCopy()` 里；改一处时长时，注意 `await wait(字数 × step + 680 + 160)` 这段衔接也要同步。

## 常见修改

- **文案**：所有双语文本都带 `data-zh` / `data-en`，属性值和元素初始文本要一起改。页脚的 GitHub 标签是固定文本，不参与切换。
- **名字**：改 `.name` 的 `data-zh` / `data-en` 和初始文本即可，样式不依赖字数。
- **渐变**：改 `:root` 和暗色媒体查询里的 `--sweep-gradient`。渐变只裁剪到文字上，背景始终是纯色。
- **文字裁切**：`.ch`、`.name`、`.line [data-zh]`、`.gh-label` 上的 `padding-block: 0.18em` 与 `margin-block: -0.18em` 必须成对保留，前者给渐变留绘制余量，后者抵消位移。
- **页脚**：两条备案必须在同一行。移动端靠 `clamp(8.5px, 2.5vw, 12px)` 收字号，`footer a` 上的 `white-space: nowrap` 不要去掉。
- **默认语言**：脚本读 `localStorage.site-lang`，没有记录时用中文；切换后写入 `zh` / `en`。
- **无 JS / 弱动态**：没有 JS 时不会加 `intro` 类，页面直接显示最终内容；系统开启「减少动态效果」时同样跳过动画。

## 部署

当前线上在阿里云服务器（`starvoid.top`），Nginx 直接托管静态文件，改动只需替换 `index.html`。

- 上传前在本机算好 `sha256`，上传到 `/tmp` 后远端复核一致，再 `install` 到临时文件并原子改名，改动前留一份带时间戳的备份。
- 只上传静态文件；密码、令牌、证书私钥不进仓库，也不写进命令历史。
- `robots.txt` 和 `sitemap.xml` 与 `index.html` 一起上传，同样校验 sha；三者都放在站点根目录，由 Nginx 直接返回。
- 部署后自检：线上 `sha256` 与本地一致、首页 200、文件大小正确、中文/英文/重播/弱动态正常、页脚仍是一行。

仓库 `JIANG-R98.github.io` 仍保留 GitHub Pages 的配置，但它不是当前线上来源；如果要推送，先确认是否要与服务器版本同步。
